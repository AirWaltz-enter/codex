# FastMoss女士运动服饰选品系统 V3 快速选品版

在既有V2.1上增量升级，筛选美国站女士运动外套、运动长袖、运动套装、运动裤。普通女装不能仅凭seamless、quarter zip、outerwear等词进入运动方向。没有销量预测保证，不为增加数量降低门槛或伪造数据。

## Windows快速使用

1. 安装Python 3.10+（建议官方Python 3.12/3.13），完整解压工具。Windows桌面尚未实测。
2. 把最新FastMoss原始 `.xlsx` / `.xlsm` 放入 `01_FastMoss原始表`；跳过 `~$` 临时文件，默认只读取修改时间最新的一个文件。
3. 双击根目录 **运行V3.bat**。第一次或依赖版本不符时才安装固定依赖，需要联网；已有依赖时直接启动。
4. 在 `02_筛选后表格` 查看 `FastMoss_V3推荐商品.xlsx`、`人工复查.xlsx`、`删除记录.xlsx`。推荐表为空时先看复查，不能认定数据丢失。控制台、每份报告“运行说明”和 `V3运行汇总.txt` 都显示推荐/复查/删除数量。
5. 默认保留V2.1人工图片确认门槛。在 `人工复查.xlsx` 的蓝色列选择正确的 **图片判断**，再将 **图片审核状态** 设为“确认运动服饰”；不符合则选择“非目标”，看不清选择“无法确认”。保存并关闭所有报告后，再双击运行V3.bat。
6. 合格且数据齐全的已确认商品进入推荐表，按评分从高到低排列。结合1688搜索词找货，填写供应链状态、审核状态和备注。

**审核状态=老板审核**（待审核/推荐/放弃）；**图片审核状态**是另一字段。老板选择“放弃”沿用原行为：保留记录与分数，不替代图片或文字筛选。

V3人工状态统一读取上述三份V3报告；轻量报告和兼容清洗结果不是审核入口。首次运行可从旧 `选品报告.xlsx` 迁移可兼容审核，随后请勿继续在旧V2报告填写V3审核。三份报告要一起保留，程序不会静默忽略缺失报告或冲突审核。

## 分类与规则优先级

|自动分类|范围|
|---|---|
|A 女士运动外套|运动夹克、瑜伽拉链外套、运动防风外套等|
|B 女士运动长袖|明确长袖的运动/瑜伽/健身上衣|
|C 女士运动套装|运动两件套、瑜伽套装、tracksuit等|
|D 女士运动裤|瑜伽裤、leggings、运动长裤、运动喇叭裤等|
|E 其他|无法归入四类的商品，不能直接成为推荐|

分类使用标题、类目、标签。夹克可以是长袖，不应误归为普通长袖；套装可以含裤子。明确标题与类目/标签冲突时复查，不能只看其中一项。

1. **硬规则优先**：男款、儿童、男女同款、hoodie/sweatshirt、dress/swimsuit/bikini/lingerie/bra/sleepwear、blazer/fashion coat等非目标，以及原下架、非美国、非正增长、超过年龄窗口等条件会被排除。人工图片确认和AI均不能绕过。
2. 英文匹配词边界，women不等于men，hooded jacket不等于hoodie；具有sports/running等明确运动证据的女士带帽夹克可成为候选。
3. 普通保留词与排除词冲突进入复查，例如yoga training coat；但标题明确hoodie或男款等仍执行第1条硬排除。这是需求中两类规则的优先级解释。
4. 缺少女款证据、运动款式不明确、数据缺失/无效、品牌风险、图文冲突等进入复查。仅有seamless/quarter zip/outerwear不能证明运动用途；没有运动证据的普通女装排除。
5. 原90天年龄、正增长、状态、美国站规则仍从 `scoring_config.json` 继承；不覆盖原配置。新品0–30天，成长款31–90天，老款91天起。评估老款需由使用者明确调整 `max_age_days`，程序不会自行放宽。

## 数据与100分评分

V3前15列按要求输出：商品图片、商品名称、商品链接、类目、7天销量、7天销售额、增长率、达人数量、评分、等级、生命周期、1688搜索词、审核状态、供应链状态、备注。后续列提供自动分类、潜力评分、图片判断/置信度/审核状态、分项、原因、原始行号、记录键和来源链接。

|分项|默认档位|最高分|
|---|---|---|
|7天销量|≥1000:30；≥300:22；≥100:15；≥30:8；≥1:3；0:0|30|
|商品销量增长|>300%:20；100%–300%:15；30%–<100%:10；0%–<30%:5；缺失/负增长:0|20|
|达人数量|≥50:15；≥20:10；≥5:5；0–4:0；缺失:0|15|
|类目匹配|四类且运动证据明确、无分类冲突:15；有分类冲突:5；无法匹配:0|15|
|价格|整个美元价格区间符合对应参考区间:10，否则0|10|
|关键词趋势|原表数值关键词增长率≥30%:10；≥10%:5；≥0%:2；负增长/缺失:0|10|

销量、达人、趋势档位和价格范围在 `scoring_v3.json` 独立配置。默认外套$25–45、长袖$20–35、套装$30–50、运动裤$20–35。用户未指定的档位与长袖价区间为可修改默认值。为了验证市场需求，默认7天销量低于30进入复查，不自动推荐。

等级A≥80优先开发；B65–79测试；C50–64观察；D<50暂不上架。分类字母与等级字母是不同概念。

**关键数据要求：**

- 识别 `近7天销量`、`7天销量`、`近7日销量`、`销量(近7天)` 等明确周期列。若同时有泛用“销量”和7天列，优先7天列。泛用“销量”仍清洗，但周期不明进入复查，不显示为已确认7天销量，也不使用总销量代替。
- 达人字段支持 `达人数量`、`带货达人数量`、`带货达人数` 等；缺失/负数/非整数计0并进入复查。
- 关键词趋势需要原表 `关键词增长率` / `关键词趋势增长率` / `关键词搜索增长率` 等数值列。缺失计0并进入复查。程序没有自动获取外部搜索趋势，不把热词命中、样本词频或商品销量增长冒充关键词趋势。
- 7天销售额仅使用明确7天销售额/GMV列；缺失留空，不以价格×销量推算。没有做币种换汇。
- 增长 `40%`=40%；Excel百分比格式0.4=40%；普通数值40默认=40%，遵循原 `growth_numeric_mode`。关键词增长率使用相同解析模式。
- V3六项自动评分最高100分。保留旧图片吸引力字段供参考，但不再额外加15分。修改审核后需重跑，Excel不自动重算筛选结果或排序。

## 图片辅助审核

默认 `scoring_v3.json → vision.enabled=false`：不调用AI。图片判断默认“无法确认”，置信度留空；人工审核不伪造AI置信度。

图片判断支持：女士运动外套、女士运动长袖、女士运动裤、女士运动套装、普通服饰、无法确认。长袖为本次四类目标补充选项。

已实现可选OpenAI兼容图片接口。启用前设置HTTPS `vision.endpoint`、真实可用的 `vision.model`，并在本地环境变量 `FASTMOSS_VISION_API_KEY` 中设置密钥；配置只存变量名，不存密钥。模型须支持图片与JSON返回。默认20秒超时、0.8置信度阈值，实际接口可能收费。

AI分析图片后输出辅助分类与0–1置信度，有低置信度、普通款或图文冲突时建议复查；模型置信度是自报值，不是经验证准确率。AI不会自动将状态改为“确认运动服饰”，有效人工图片确认可以解决AI误判，但文字硬排除始终有效。没有推断模特个人性别。

已实现按图片内容、模型和接口缓存AI结果，重跑避免重复调用；网络图片仍通过原下载器处理。图片变化审核失效依赖标题/类目/标签/图片URL/原嵌入图片内容指纹；同一URL背后换图尚不能仅靠来源指纹检测，请人工核验。

本次仅测试了AI接口合同、缓存、失败及冲突处理，没有用户API密钥，**未验证任何真实模型识别效果**。不开启AI也可完成完整人工审核流程。

默认 `require_image_review=true`。若使用者明确要文字合格先进入候选，可自行改为false；这不能绕过文字/数据规则，且图片无法确认的风险仍需人工处理。本次没有擅自关闭原图片审核门槛。

## 输出与旧流程

- `FastMoss_V3推荐商品.xlsx`：按评分排序的推荐商品，附运行说明和所有原工作表单元格副本。
- `人工复查.xlsx`：待审核、图文冲突及数据不足商品，含具体原因。
- `删除记录.xlsx`：每条保留删除原因和来源。明确被排除的商品不额外联网下载图片，仍保留源图片链接。
- `FastMoss清洗结果.xlsx` 及时间戳副本：保留原FastMoss筛选表、删除记录和1688同款数据区域。仅列通过的商品，是兼容快照，不是人工审核入口。
- `cleaned/Fastmoss_待搜款清洗表.xlsx`：原15列保持顺序，在后面扩展。被排除/复查项强制是否进入搜款=否，保留旧裁剪和搜款状态，不删除既有1688任务。
- `FastMoss_V3推荐商品_轻量.xlsx` / `人工复查_轻量.xlsx`：无图反馈文件，不作为审核状态来源。
- `03_商品图片`：原图片下载与嵌入功能保留。主要V3报告使用可随单元格移动的浮动图片；旧兼容输出沿用单元格图片，需要支持该特性的Excel/WPS版本。
- `清洗进度.log`：读取、分析、下载/复制图片、生成报告的数量与百分比。
- `error.log`：配置/输入/输出错误栈及单张图片/AI失败记录；错误保留历史，不表示每次运行都失败。

所有V3商品报告冻结表头、筛选、自动列宽、可点击链接及等级/生命周期颜色。旧结果保留原标题行，冻结标题和表头。原输入文件不修改；原始数据副本保留单元格内容，原公式作为文字，不执行导出表内指令；完整原格式和原图以原文件为准。

人工报告重跑前备份，三份V3报告先全部写临时文件，再替换；普通替换失败会回滚已替换文件。其他兼容表/标准表独立保存，整批不是数据库事务；断电或文件系统故障时可用backup恢复。

## 1688辅助与命令行

中文搜索词按分类及标题生成：Quarter Zip Running Jacket→女款半拉链运动外套；跑步防风外套；瑜伽训练外套。Flare Leggings→无缝喇叭瑜伽裤；高腰提臀喇叭裤。搜索词只是建议，不证明材质或工艺为无缝，找货时需核实。

保留原图片嵌入、搜款准备与裁剪、队列检查、1688人工执行台、结果及汇总功能。没有自动抓取1688、确认同款或供应商资质。

在04_脚本目录运行：

```bash
python -m pip install -r requirements.txt
python fastmoss_cleaner.py --mode v3
python fastmoss_cleaner.py --mode v3 --input "../01_FastMoss原始表/你的原表.xlsx"
python fastmoss_cleaner.py --mode v3 --root "你的数据根目录"
python fastmoss_cleaner.py --mode v3 --as-of 2026-07-11 --no-download-images
python -m unittest discover -s tests -v
```

`--no-download-images`仅跳过网络，仍复制原表嵌入图片；不是图片服务或视觉识别成功的证据。无参数Python入口和原运行V2.bat继续走V2.1兼容模式，新功能请使用运行V3.bat或--mode v3。V2与V3人工报告各自为源，不自动双向同步。
